Commandes git :

Voici quelques commandes GIT essentielles que vous devez connaître :

  • git init : Initialiser un nouveau dépôt GIT
  • git clone : Cloner un dépôt existant
  • git add : Ajouter des fichiers à l'index
  • git commit : Enregistrer les modifications
  • git push : Envoyer les modifications vers le serveur distant
  • git pull : Récupérer les modifications depuis le serveur distant
  • git branch : Gérer les branches
  • git merge : Fusionner des branches
